# GameSlime — arquivos visuais de um experimento de jogo

**Repositório histórico contendo recursos gráficos relacionados a um protótipo de jogo com slimes.**

## O que está aqui

A pasta `sprites/` reúne recursos visuais usados ou preparados para o experimento. Esta versão **não contém uma aplicação executável documentada**, nem um fluxo de instalação definido.

## Projetos relacionados

Para acompanhar o desenvolvimento atual do universo Slimekeepers, consulte:

- [Slimekeepers: Lost Valley — Godot 2D](https://github.com/HelioConde/Slime-Harvest).
- [Slimekeepers: Lost Valley — outra implementação](https://github.com/HelioConde/Slimekeepers-Lost-Valley).
